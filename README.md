## 📖 Descripción

**Café Pub La Luna** es una aplicación web desarrollada como Trabajo Fin de Grado (TFG) para la gestión integral de eventos, reservas y venta de entradas.

## 🚀 Características Principales

### 👥 Usuarios
- Consulta de próximos eventos.
- Compra de entradas online.
- Generación automática de entradas PDF.
- Código QR único por entrada.
- Reserva de mesas VIP.

### 🔐 Administración
- Gestión completa de eventos.
- Gestión de reservas.
- Control de ventas.
- Estadísticas en tiempo real.
- Control de aforo.

### 📊 Dashboard Estadístico
- Entradas vendidas.
- Ingresos totales.
- Eventos activos.
- Porcentaje de ocupación.
- Gráficos de ventas y rendimiento.

## 🛠️ Tecnologías Utilizadas

### Frontend

### Backend
